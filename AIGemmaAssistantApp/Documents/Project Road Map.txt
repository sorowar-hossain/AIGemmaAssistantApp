What is a context window?
A context window is the maximum number of tokens a model can process in one sequence. 
It includes both the prompt and the generated response.
***The number of tokens of a text depends on the tokenizer used by your Gemma model.

**Measure prompt tokens, manage old messages, and prevent the prompt from exceeding the available capacity.

KV Cache: 
Stores previously calculated Key and Value tensors to make token generation more efficient.
*** tensors
	It's a nemurical representation of token arranged in one or more dimention that is matrix representation.

*****Understand what we are implementing
When you chat with Gemma, it generates an answer one token at a time. 
To generate each new token, the Transformer uses attention over earlier tokens.
Without caching, the model may need to recompute key and value representations for previous tokens. 
With a KV Cache, it can reuse those stored representations.

******Every time GenerateNextToken() runs, 
	  the runtime handles the model's generation state, including its KV Cache.

	  Your existing Microsoft.ML.OnnxRuntimeGenAI library manages the KV Cache internally during token generation. 
	  You don't need to create your own Key and Value tensors.
	  ONNX Runtime GenAI library manages the KV Cache intern
